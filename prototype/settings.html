使用帮助

常见使用问题和解决方法

DiyarDesk 频繁闪烁或重启，怎么办？

如果系统壁纸会定时自动切换，切换时可能让 DiyarDesk 闪烁或反复重启。请把常规壁纸改成不会自动切换的固定背景。

  1. 打开 Windows 设置 → 个性化 → 背景。
  2. 将“个性化设置背景”设为“图片”或“纯色”，不要选择“幻灯片放映”或“Windows 聚焦”。
  3. 改完后重新打开 DiyarDesk。

导入主题说明

点击“+ 导入主题…”即可选择本地文件，以下类型均已支持并会自动验证与包装：

支持的格式与导入方式

  • 主题包（.zip / .deskland） — 多文件 HTML/JS/CSS/资源包。若包含 manifest.json 或 theme.json，将自动读取名称、说明、入口文件、封面图与参数分组；否则默认使用 index.html 或首个 .html 作为入口，自动识别 thumb/preview 封面图（含 .svg），并拦截路径穿越（zip-slip）与异常软链接。
  • 单个网页（.html / .htm） — 单文件交互式着色器或网页主题，会自动读取 <title> 标签作为主题名称。
  • 图片壁纸（.png / .jpg / .jpeg / .webp / .gif / .svg / .avif / .bmp） — 自动包装为壁纸页面，附带柔和环境缩放/漂移、亮度（brightness）、动效强度（motion）、图标背板光晕（dimIcons）与自适应/截图分享能力（desklandSnapshot）。
  • 视频壁纸（.mp4 / .webm / .mkv / .mov） — 自动循环静音播放，提供亮度（brightness）、播放速度（speed）与图标背板光晕（dimIcons）调节。

导入前会校验压缩包完整性（单包上限 150 MB / 2000 个文件）；已导入的主题保存在用户目录中，随时可在右侧预览栏点击“移除”。

Manifest 清单与参数格式（manifest.json / theme.json）

  • 基础字段与封面 — 支持 name/title、desc/description、entry/page/main/file（默认 index.html）、adaptive（true/false），以及 thumb/thumbnail/preview（图片路径含 .svg 或 CSS 渐变/颜色）。
  • 参数定义（groups 或 settings） — 兼容 DiyarDesk 原生 groups 数组（[{ name, params }]）以及按 group/category 分组的 settings 对象；支持滑块（range: min/max/step/default）、单选（select: 字符串数组或 { label, value } 选项）和开关（checkbox: true/false）。

交互式 HTML 主题通信协议

  • 初始化握手（ready） — 桌面模式下调用 window.chrome.webview.postMessage('ready')，预览模式下（?preview=1）调用 parent.postMessage(JSON.stringify({ t: 'ready' }), '*')，以立即接收初始设置和图标位置。
  • 宿主消息与截图 — 页面会收到 { t: 'icons', vis, r: [[l, t, r, b], ...] }（物理像素坐标，CSS 像素需除以 devicePixelRatio）、{ t: 'settings', v: {...} }、{ t: 'reset', v: {...} } 和 { t: 'pause', v: true|false }；可选导出 window.desklandSnapshot() / window.desklandRecord() 以支持一键分享。
